## Prose · The same loop, in code

```python
ids = tokenizer.encode("The capital of France is")   # [128000, 791, 6864, 315, 9822, 374]
while True:
    logits = model(ids)             # forward pass over the WHOLE sequence
    next_id = logits[-1].argmax()   # or sample from softmax(logits[-1])
    ids.append(next_id)             # output becomes input
    if next_id == EOS:              # 128001, <|end_of_text|>
        break
print(tokenizer.decode(ids, skip_special_tokens=True))
```
