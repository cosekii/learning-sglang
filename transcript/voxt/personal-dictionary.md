## Prose · Where this chapter's claims come from

Step 1 reads the term and its parts. A term is `store.Term`: `Term`, `Aliases`, `Note`, `Enabled`, timestamps. `Clean` trims each to one line, drops empty aliases, the term itself and case-insensitive duplicates, and keeps at most `MaxAliases = 10`; `Check` refuses an empty term, a newline, or more than `MaxTermChars = 80` runes (`dict.go`).

Step 2 reads the four destinations and their switches. `SpeechHints` returns `dict.Hints` only when `Dictionary.Enabled && Dictionary.ASRHints` (`session/run_audio.go`). `spoken()` replaces aliases only when `Dictionary.Enabled` (`session/cleanup.go`). `glossary()` builds `compose.Term` list only when `Dictionary.Enabled && Dictionary.Glossary` (`session/run_transcribe.go`). `PromptDictionary` returns `Notes` only when `Dictionary.Enabled && !NotesOff` (`session/text.go`).

Step 3 reads `dict.Hints`: it clones the terms, sorts stable by `UpdatedAt` descending, keeps enabled ones once (ignoring case via lower-cased key), and returns each term as one line. Aliases are not included; the doc comment says they are what recognition gets wrong.

Step 4 reads `dict.Replace` and `matchText`. Enabled terms' aliases are matched; Latin aliases need word boundaries on both ends (`wordRune`), CJK aliases match anywhere; patterns are sorted longest first; a term already written as itself is kept (it is only added as a pattern when `highlight`). `spoken()` in `session/cleanup.go` calls `dict.Replace(raw, r.terms)` and is called before `transcribe()` in `session/run.go:301,312`.

Step 5 reads `compose.Glossary`: a dictionary of at most `GlossaryAllUpTo = 30` terms goes in whole; a larger one keeps only terms whose spelling or alias appears in the text (spaces, `-`, `_` removed, case-folded), then stops at `MaxGlossaryTerms = 60` lines or `MaxGlossaryChars = 2000` characters. Lines read `- Term (heard as: alias)`; Chinese uses `（可能被听成：…）`.

Step 6 reads `PromptDictionary` and `addDictionary`: the note is trimmed and added as the `dictionary` layer after the task layers and before scene, glossary and input, so the system-prompt prefix stays stable (`compose/dictionary.go`). It is never passed to ASR or to `dict.Replace`.

Step 7 is a status read: `SpeechHints` and `spoken()`/`dict.Replace` do not call the language model; `Glossary` and `addDictionary` are only used when a cleanup request is built.
