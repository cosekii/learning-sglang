## Prose · Where this chapter's claims come from

Step 1 separates three things. The app is 280 MB and the dmg 45 MB (`Voxt/docs/release.md`, the 0.1.0-beta.1 size table). The default speech model is the catalogue's `asr.accurate` entry: nine files totalling 2,467,856,503 bytes, of which `model.safetensors` is 2,463,307,541 (`Voxt/internal/models/catalog.go:199-215`). The model library defaults to `~/Library/Application Support/SGLang Omni/models` (`Voxt/internal/models/hub.go:106-119`, `catalog.go:6-14`). The app bundle carries the helper and the omni runtime (`docs/release.md`).

Step 2 reads the pin. Each entry has a Hugging Face repo, one pinned revision, accepted other commits, and a file list with sizes and catalogue fingerprints (`catalog.go:84-154`). `Entry` copies the listed SHA-256 only for LFS files; non-LFS files are checked by git blob ID (`hub.go:28-44`, `internal/models/models_test.go:235-250`). The shown entry's revision is `a8379a2e2f9e313c9292cdf1af4055ab56d50d55` (`catalog.go:203`). The snapshot folder is `$HUB/models--<owner>--<name>/snapshots/<commit>`, using that full revision (`hub.go:89-104`).

Step 3 reads the download. `Entry` turns the catalogue into hfhub's files: only the listed files, with SHA-256 verification for LFS and git blob IDs for the others (`hub.go:28-44`). A mismatch is an error; no automatic second fetch is claimed. `Manager.Download` adds the entry's missing needs, sums their sizes, and runs one job whose `run` loop fetches the models in sequence (`Voxt/internal/models/manager.go:254-291`, `319-339`). A cancel keeps what arrived (`manager.go:293-303`); partial blobs resume (`internal/models/manager_test.go:458-482`), and a stopped download's `Done` is what it kept (`manager.go:60-63`). `ReserveBytes` is the room a download leaves free; zero means hfhub's 2 GB (`manager.go:33-35`). The default speech model needs Silero VAD (`catalog.go:201`), whose two files are 463 and 1,237,860 bytes (`catalog.go:350-356`).

Step 4 reads the runtime. `Runtime` starts a server when a model is acquired and retires another speech model's server (`Voxt/internal/omni/runtime.go:122-143`, `191-228`). Automatic keeps `DefaultIdleTimeout` = 10 minutes; Settings can choose 5, 15, 30 or 60 minutes, or keep until quit (`Voxt/models_controller.go:280-306`, `Voxt/internal/settings/models.go:105-135`). `DefaultStartTimeout` = 180 s is a readiness timeout that stops a server which never becomes ready, not a promised load time (`runtime.go:29-30`, `44-46`). Silero has its own `silero_vad_server` beside the ASR server (`Voxt/internal/omni/models.go:60-63`, `Voxt/internal/omni/vad.go:23-44`). `Library.Delete` calls `Unload` and then requests `models.Manager.Delete` without waiting for process exit (`Voxt/internal/local/library.go:70-82`, `runtime.go:249-266`). An idle process stops asynchronously; a busy process stops after its uses end (`Voxt/internal/omni/server.go:215-229`, `253-287`). The following delete request goes through external actnowkit; its busy-model outcome is outside this chapter (`Voxt/internal/models/claims.go:40-54`).

Step 5 separates two release-update paths. With Voxt's signed feed, MyGo's updater checks every 24 hours by default, installs manually by default (a delta when available), replaces `Voxt.app` while the old version runs, then offers a restart (`Voxt/updates.go:1-16`, `68-74`, `179-209`). Automatic checks can be disabled, and optional automatic installation can install without asking; automatic installation defaults off (`updates.go:179-209`, `docs/release.md:406-410`). Until a restart the helper on disk is the new version's, so the supervisor does not start it (`helper.FailUpdated`) and a card asks to restart (`updates.go:12-16`, `245-253`); the running app watches for this every minute (`updates.go:114-116`, `213-228`). A release build without a feed cannot update itself: the GitHub fallback downloads a matching disk image, and opens the release page only when none matches (`Voxt/updates_github.go:3-18`, `361-387`). `BuildBackend` selects feed, GitHub fallback or no updater (`Voxt/internal/updates/updates.go:13-22`, `Voxt/main.go:127-136`). The beta channel is a Settings switch, on by default while the running version is a beta (`updates.go:18-24`, `187-203`). Models are not in the app (`docs/release.md`).

Step 6 is the boundary between those three mechanisms, taken from the same files.

Constructed parts: the 2.47 GB total is the decimal size of the bytes above; the model-to-app ratio (about 9×) is that total divided by the documented 0.1.0-beta.1 app's 280 MB. The `Voxt 2.0 → 2.1` update is a constructed example. No real download, update, or model process was run.
