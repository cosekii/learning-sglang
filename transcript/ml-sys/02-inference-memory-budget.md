## Prose · Where this chapter's claims come from

Step 1 reproduces the rounded worked example in `Awesome-ML-SYS-Tutorial/sglang/kvcache-code-walk-through/mem-fraction-static.md:73-85`: available memory is about 78 GB before model loading and 18 GB afterward. At `mem_fraction_static = 0.70`, KV room is −5.4 GB; at 0.85, it is 6.3 GB. These are the article's teaching values, not measurements from this computer. The formula and startup behavior were checked against SGLang source at `4fa3482`; exact files and lines are in the deep dive. Dynamic headroom is an allowance, not memory already fully occupied.

Step 2 follows the model → KV pool → graph-buffer initialization order in SGLang `4fa3482`. The graph-buffer size is not measured in this teaching example. Step 3 uses one schematic capture to show that the graph records GPU work, while fixed input and output buffers remain allocated.

This chapter covers startup sizing and the lifetimes of graph buffers and runtime activations. It does not derive KV bytes, paging, multimodal reserves, or every allocator allocation; those need separate sources and examples.
