## Prose · Where this chapter's claims come from

The 250 ms value is a constructed example from [zero-to-sglang Part I Chapter 5: Introduction to Benchmark](https://zero-to-sglang.datawhale.cc/eng/part1/Chapter5_Introduction_to_Benchmark.html), §3.1. The later token times are constructed additions to that example, not measurements from this computer. The constructed request uses `stream: true`; each SSE delta carries one output token, and the client timestamps each delta's arrival rather than waiting for one non-streaming JSON response. The TTFT and ITL definitions follow the same section and *Inference Engineering* §1.4: TTFT runs from sending a request until its first output token arrives, and ITL is the gap between neighboring output tokens. TPOT follows the course's post-first-token boundary: divide the ITL total by the number of gaps, not by all output tokens. E2E latency follows the course boundary from request sent to completion: subtract the endpoints, or add TTFT to all post-first-token gaps. The two 100-request latency distributions are constructed examples. A is based on the course's 99 fast requests and one 2 s request in §5.2; B adds 50 requests at 250 ms, 49 at 400 ms and one at 2000 ms for a same-scale comparison. P50 follows the middle-position guidance in §5.1 and *Inference Engineering* §1.4.1. P99 follows the same sources' guidance to inspect the slower requests; this chapter explicitly uses the rank method shown in Steps 5–6 rather than claiming a universal percentile algorithm. Throughput follows the course's definition in §3.2: completed requests divided by total test time. The 20-second and 25-second whole-test windows are constructed additions, not local measurements.

Scope: this chapter defines the core latency metrics, nearest-rank P50 and P99, and request throughput, then compares two constructed batches on shared scales. It leaves out workload selection, warm-up, token throughput, SLA and Goodput. Chapter 14 continues with controlled profiling rather than duplicating those topics here.
