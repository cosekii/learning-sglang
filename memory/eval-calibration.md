# 首次评分校准

日期：2026-11-22。对象：Learning SGLang 第 2、14 章；依据：bot 主目录 `EVAL.md`、仓库 `AGENTS.md` 和 `docs/deep-dive.md`。

## 统一后的判断口径

1. **#1 只评价章首，不要求后续每一步重新讲动机。** 后续步骤只要能延续本章问题，#1=2。章首有问题和前文承接、但缺少可核对数字时取 1，不把第 2 章以后各步一律误判为 0。
2. **#3 区分“示意输入”和“由输入算出的结果”。** 示意输入不需要外部事实来源，但应在图或深入讲解里标明是示意值，并让读者能复算下游结果。只在深入讲解标明、截图和 transcript 无法回答“哪来的”时取 1，不把任意示例输入当成无来源的实测数据取 0。
3. **冷读问题与事实扣分分别记录。** 冷读只使用当前截图和累计 transcript；深入讲解虽能回答，也不替冷读材料消洞。同一组数在同一过程的多次复算中不重复计数。外部源码或论文的时效性问题记入 #10，不冒充冷读者能发现的问题。
4. **#12 按“适用节是否完整”评分。** `docs/deep-dive.md` 允许没有公式或数字的步骤省略相应节，不机械要求每一步凑齐所有标题；符号来路、图上元素和衔接必须完整。
5. **已知过时内容不因深入讲解披露了就算事实正确。** 披露可保 #9、#12 的分，但 #10 仍扣分。

若把 #1 机械应用到每一步、或把教学用示意输入都当成无来源测量值，两章会被系统性压低；以上是本轮重读标准后调整的两处主要偏差，不是为了抬分而忽略图上缺口。
