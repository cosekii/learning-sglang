- 第 1 步把虚线解释为共用进程，补出 `mm_aggregate` 与「汇合输入」的对应；红框依次走纯文字进程、语音 GPU 0 和其余进程。
- 第 2 步让三条实际路线都使用蓝色，灰字说明未加载或跳过；中文 caption 改为「处理纯文字请求」。
- 第 3 步按 PR #1235 改正拓扑：talker 与 thinker rank 0 共用 GPU 4，thinker rank 1 和 code2wav 留在 GPU 5，独占 talker 使用 GPU 2。总耗时增加改用橙色，避免与红色焦点冲突。
