- 第 2、3、4、7、8 步有真实步内循环。`$effect` 读取 `step`、重置 `phase`、安排 `setTimeout` 并清理旧计时器，`nextLap()` 驱动 `<LoopProgress>`。红框是当前工作，标签为「loops · red = current／循环 · 红框 = 当前」。

- 第 1、5、6 步各只有一张静态场景，沿用第 8 章评分卡的同一规则：`StepControls` 每次只切换一张场景，因此 R6 记 2。它们不声称有步内动画。

- 首轮独立冷读指出 raw token 与 code 0 的关系不清、跨步反馈链断开、停止步概念过多、采样率推导缺失、重采样和向上取整缺少白话、512 尾巴机制不清、构造算例和章末锚点不足，以及 codebook/codes 叫法不统一。逐项修复后，终审 8/8 步 R1–R5 均为 10/10，没有必须修内容洞。
