- **第 3 步**：rank 是成员编号，broadcast 是把相同数值发给每个成员；完整张量广播后，各推理 rank 留下并装入自己的部分。主图使用 plain wording，不提前抛未解释的 API 名。
- **第 4 步**：parameter 定义为一张权重表，形状 `[256,1024]` 写成 256 行、1024 列；`4 × 256 × 1024 = 1,048,576`，与一张 1024×1024 照片的像素数相同。灰色箭头只传位置便签；收拢方便签的是推理 TP rank 0，不是训练 rank 0。内存访问细节明确不展开。

- **第 6 步**：生成在新旧混合时暂停，等当前请求结束、所有参数更新、旧 KV 不能复用和调用完成后再开始；部分失败必须弃用模型，不暗示自动回滚或崩溃安全。
