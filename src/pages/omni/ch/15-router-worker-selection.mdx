A heterogeneous cohort buffers and classifies the body before selection, then forwards the original bytes (`http_generation/classify.rs:48-120`). Code references in this chapter pin to `sglang-omni origin/main@3a31bd72e034db37ce5115a03dd4827b449683be`. Examples are constructed from source rules; the chapter does not run a router or benchmark.
